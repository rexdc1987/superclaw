SuperClaw 服务端 — 使用说明
==============================================================

一、怎么启动
--------------------------------------------------------------
双击 start_superclaw.bat。

会出现一个黑色窗口，窗口里会打印：

    服务启动中 → http://127.0.0.1:8987/  局域网 http://192.168.x.x:8987/

等几秒，浏览器会自动打开。**这个黑窗口不能关**，关掉就等于停止服务。

二、别的电脑怎么访问
--------------------------------------------------------------
让其他同事在浏览器里输入「局域网」后面那个地址，例如：

    http://192.168.1.23:8987/

手机、平板同样可以用浏览器打开。

连不上的话按顺序检查：
  1. 这台机器的黑窗口是不是还开着（服务必须在运行）
  2. 两台电脑是否在同一个局域网 / 同一个 WiFi
  3. Windows 防火墙是否放行了 8987 端口（安装程序会自动加规则；
     如果手动解压的绿色版，需要自己放行，见下面第五条）

三、改端口 / 改配置
--------------------------------------------------------------
端口和执行模式在：data\instance.json
    "port": 8987            改成别的端口后重启服务生效
    "execution_mode": "api" 看板/控制端用 api；本机要跑红果 RPA 才改 embedded

数据库、AI 密钥、登录密钥在：app\config\local.yaml
自动更新**不会**覆盖这个文件，可以放心改。

四、怎么升级
--------------------------------------------------------------
方式一（推荐）：登录系统后，页面顶部会提示「发现新版本 vX.Y.Z」，
点「立即更新」，下载完成后点「重启并更新」，服务会自动替换并重启。

方式二：到 Gitee 发行版页面手动下载最新的
        SuperClaw-server-X.Y.Z.zip，解压覆盖（保留 data\ 目录）即可。

data\ 目录里放的是本机数据、日志、更新缓存，升级时永远不动。

五、手动放行防火墙（只在你手动解压绿色版时需要）
--------------------------------------------------------------
用**管理员身份**打开 PowerShell，执行：

    New-NetFirewallRule -DisplayName "SuperClaw 8987" -Direction Inbound `
      -Protocol TCP -LocalPort 8987 -Action Allow -Profile Private

六、目录说明
--------------------------------------------------------------
    runtime\        Python 运行时，不要动
    app\            程序主体，升级时会被整体替换
                    （app\config\local.yaml 例外，它会被保留）
      launcher.py     启动器：先应用更新，再拉起服务。
                      它住在 app\ 里，所以能跟着更新一起升级
    data\           本机数据，升级永不动
      instance.json   本机端口等设置
      logs\           日志
      screenshots\    截图
      updates\        自动更新下载缓存
    start_superclaw.bat  双击入口。它只是个几行的启动桩，
                         真正的逻辑在 app\launcher.py
    VERSION         当前版本号

七、出问题了怎么查
--------------------------------------------------------------
1. data\logs\launcher.log       启动器日志（启动失败先看这个）
2. 黑窗口里最后几行报错信息
3. 确认 data\instance.json 里的 port 没有被别的程序占用
4. 页面右上角版本号旁边出现「进程仍运行 vX.Y.Z」的黄色提示，
   说明更新包已经装好但服务进程还在跑旧代码：关掉黑窗口，
   再双击 start_superclaw.bat 就恢复正常了
